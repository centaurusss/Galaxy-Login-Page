# 🌌 Galaxy Login Page

## Description
A modern **Galaxy-Themed Login Page** built with **HTML5**, **CSS3**, and **Vanilla JavaScript**.  
Featuring a **beautiful night sky animation** with **moving stars** and a **glassmorphism-style login form**, this project showcases elegant design and smooth UI aesthetics.  
Perfect for use in modern web apps, portfolios, or as a UI experiment.

---

## ✨ Features
- 🌠 **Animated starry background** using JavaScript Canvas  
- 💎 **Glassmorphism login card** with smooth blur effect  
- 🎬 **Fade-in animation** for a professional look  
- 🌈 **Gradient galaxy color theme** (purple-blue night sky)  
- 🧠 Interactive floating labels on input fields  
- 💻 Fully responsive and lightweight — no frameworks required  

---

## 🚀 How to Use
1. Clone or download the repository  
2. Open `index.html` in your browser  
3. Enjoy the **animated galaxy login experience**  

You can customize:
- Colors & gradients in `style.css`
- Star count & speed in `script.js`
- Form fields and links in `index.html`

---

## 🛠️ Technologies
- **HTML5** → structure  
- **CSS3** → styling, animations, glassmorphism  
- **Vanilla JavaScript** → star animation with canvas
